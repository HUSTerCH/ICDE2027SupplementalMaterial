# 醒悟因素分类体系

## 1. 分类对象与范围

本分类体系记录案件中实际发生的诈骗识别或终止事件，以及引发这些事件的触发因素。它包含8个类别，区分外部主体主动介入、受害人主动求证、诈骗过程中出现的异常，以及使互动无法继续的客观条件。

“醒悟”这一阶段同时覆盖认识到诈骗和进一步付款终止。因此，某些标签描述受害人已经识破骗局的事件，另一些标签描述资金或互动被阻断的事件。资源耗尽、技术划款被发现或诈骗者退出等，不必然意味着受害人在此前已经形成完整的诈骗判断。

标签以整起案件为单位，可以多选；各标签需要有独立的触发证据。分析既查看醒悟阶段，也回溯转账和诱导阶段末尾的事件，以确认“为什么在此时停止或识破”。

## 2. 分类总表

| 类别 | 标签代码 | 核心触发方式 |
|---|---|---|
| 外部系统干预 | `System_Intervention` | 警方、银行或其他机构系统主动预警、拦截或介入。 |
| 亲近社会关系干预 | `Social_Intervention` | 家人、朋友或同事等熟人劝阻，或受害人向这些人询问后被点醒。 |
| 主动外部求证 | `External_Validation` | 受害人向权威渠道或被冒充的真实对象主动核实，获知诈骗。 |
| 反诈认知触发 | `Fraud_Awareness_Trigger` | 已有反诈知识、主动查阅的反诈内容或相似案例帮助受害人识别诈骗。 |
| 内部逻辑崩溃 | `Internal_Logical` | 受害人识别诈骗叙述中的矛盾或荒谬要求，信任崩塌并拒绝继续。 |
| 承诺落空 | `Commitment_Failure` | 具体承诺不能兑现，且这一失败直接使受害人识破骗局。 |
| 诈骗者退出 | `Attacker_Disengagement` | 诈骗者主动断联、拉黑、解散群组或关闭平台等，导致案件终止或被识破。 |
| 客观终止 | `Objective_Termination` | 资金耗尽、非授权划款被发现、物理通信中断等条件使过程被动终止。 |

## 3. 八个类别的详细说明

### 3.1 外部系统干预：`System_Intervention`

**定义。** 公权力机关或金融、通信、支付等机构系统主动预警、阻断或介入，使受害人识别诈骗或停止进一步付款。

**典型证据。** 反诈预警、警方主动打电话或上门劝阻、银行主动核查异常转账、银行卡被风控锁定或交易被拦截。

**判定边界。** “系统”既包括自动风控，也包括机构工作人员或警方的人工介入。关键是外部机构主动发现风险并采取行动。受害人自己去银行或派出所求证，属于主动外部求证，而不是因为对象是银行或警方就归入本类。

### 3.2 亲近社会关系干预：`Social_Intervention`

**定义。** 家人、朋友、同事等现实社会关系中的人员介入劝阻，或受害人主动询问这些人后得到提醒并识别诈骗。

**典型证据。** 家属发现异常付款后制止、同事提醒所述情况属于骗局、受害人向朋友讲述经历后被点醒。

**判定边界。** 联系熟人可以是主动求助，但对方的作用是作为熟人提供提醒或劝阻。如果联系的是被冒充的真实对象，目的在于核验身份或请求是否真实，则使用主动外部求证。

### 3.3 主动外部求证：`External_Validation`

**定义。** 受害人产生疑问后，主动向权威渠道或被冒充者本人核实，并通过明确的外部确认认识到诈骗。

**典型证据。** 前往银行柜台、拨打官方客服、到派出所询问，或直接联系真正的领导、亲友、机构及其他被冒充对象，确认相关要求并非其本人提出。

**判定边界。** 需要有实际求证及获得确认的记录。“想去问问”“准备核实”或单纯寻找帮助，尚不等同于已由求证触发醒悟。该类与系统干预的区别是受害人主动发起核实，与熟人干预的区别是核验的对象和作用。

### 3.4 反诈认知触发：`Fraud_Awareness_Trigger`

**定义。** 受害人通过接触、回忆或主动查找反诈内容，重新理解当前经历并识破骗局。

**典型证据。** 搜索发现相似诈骗案例、看到反诈节目或平台反诈提醒、接触同类案件受害人的揭露、回想此前接受过的反诈教育。

**判定边界。** 案件仅写受害人“以前接受过反诈宣传”，而没有说明这些知识促成了当前识别，不赋予该标签。根据提醒的实际作用区分：反诈知识或相似案例触发认知，属于本类；针对当前案件的机构主动阻断，依据系统干预判定。

### 3.5 内部逻辑崩溃：`Internal_Logical`

**定义。** 诈骗者仍在维持联系、编造理由索款，受害人凭自身常识发现叙述矛盾或要求荒谬，主动拒绝并识破骗局。原始提示词中也称“逻辑信任崩塌”。

**典型证据。** 每次满足要求后规则继续改变、不断要求补单、要求再交费才能取回前款，以及其他使受害人意识到解释无法成立的逻辑矛盾。

**判定边界。** 需要定位信任崩塌的具体依据。“越想越气”“心里发毛”等没有事实支撑的直觉，不能独立支持该标签。仅仅发现银行卡的钱被划走，属于被动发现损失，不能直接当作逻辑识破。

### 3.6 承诺落空：`Commitment_Failure`

**定义。** 诈骗者给出了具体可兑现的承诺，受害人在尝试获得承诺结果时发现其无法实现，并因此认识到诈骗。

**典型证据。** 约定的款项迟迟不到账、无法按承诺提现、未收到商品或收到的商品明显不符等，且叙述明确将该失败与识别联系起来。

**判定边界。** 承诺存在或尚未兑现，不自动成为醒悟因素。需要确认“无法兑现”实际触发了识别。若案件主要因对方拉黑、平台关闭而被识破，提现显示审核中等伴随状态不自动增加该标签。

### 3.7 诈骗者退出：`Attacker_Disengagement`

**定义。** 诈骗者主动停止联系或撤离，使受害人无法继续互动，进而终止付款或意识到诈骗。

**典型证据。** 被对方拉黑、联系渠道全部失效、诈骗群解散、店铺注销、平台关闭或无法再登录。

**判定边界。** 应结合案件描述确认主动撤离或失联情节，区分普通设备或网络故障。若资金被骗后对方立即断联，断联本身是独立触发点；不能仅因同一时段尚未提现，就再推定一个独立的承诺落空因素。

### 3.8 客观终止：`Objective_Termination`

**定义。** 受害人的客观支付能力或继续互动的条件消失，或其被动发现未授权损失，使诈骗过程停止。

**典型证据。** 资金耗尽且无法继续借款、发现未授权扣款或盗转、设备或物理通信渠道中断等。

**判定边界。** 资金困难需要与无法继续付款的事实相联系，不能仅凭经济背景推定。停止付款可能先于完整识破；例如受害人仍相信对方，但已无法筹到下一笔钱。随后如又主动向警方求证并获知诈骗，两种独立机制可以共同记录。

## 4. 关键判别边界

| 容易混淆的类别 | 判别问题 |
|---|---|
| 系统干预与主动外部求证 | 是机构主动联系、预警或阻断，还是受害人主动向外核实？ |
| 熟人干预与主动外部求证 | 熟人的作用是劝阻提醒，还是作为被冒充的真实对象确认身份或请求不实？ |
| 反诈认知触发与系统干预 | 是反诈内容使受害人识别模式，还是外部系统针对该案主动采取行动？ |
| 内部逻辑崩溃与承诺落空 | 是受害人看出解释或要求自相矛盾，还是某个具体承诺不能兑现并直接触发识别？ |
| 内部逻辑崩溃与客观终止 | 是主动识破并拒绝，还是仅发现钱被划走或客观上无法继续付款？ |
| 诈骗者退出与承诺落空 | 是对方主动失联或平台关闭触发识别，还是受害人因未得到约定结果而识破？ |

同一案例存在多个独立触发因素时可以多标签；上述区别不意味着所有类别之间都互斥。

## 5. 证据与多标签原则

1. 先定位最后的识别、拒绝、求助或停止付款事件，确认案件如何结束。
2. 回溯此前的索款、转账、核验及通信变化，寻找实际触发点。
3. 区分已经发生的事件与受害人的计划、猜测或背景信息。
4. 每个标签对应独立证据；不把同一事件换一种说法后重复作为多个机制。
5. 仅记载“意识到被骗后报警”时，不根据报警行为本身猜测醒悟类别，需要继续查看之前的具体情节。

例如，受害人借款申请被拒、客观上已无法继续付款，随后去派出所询问并被告知诈骗，可以同时记录 `Objective_Termination` 与 `External_Validation`。两个标签分别描述支付能力阻断和主动求证确认。

如果受害人因发现对方拉黑、平台关闭而识破，不能只凭此前有一笔提现仍在审核，就自动增加 `Commitment_Failure`；需要额外证据说明未兑现承诺本身也是独立的识别触发点。

## 6. 标签表示与对应提示词

微调版使用 `<|External_Validation|>` 等特殊token，baseline版使用 `<External_Validation>` 等普通文本形式。标签名称与含义不随表示方式改变。

任务输出包含分析文本与标签数组，例如：

```json
{
  "analysis": "客观上无法继续筹款，随后主动向警方核实并确认被骗。",
  "labels": [
    "<Objective_Termination>",
    "<External_Validation>"
  ]
}
```
