# 诈骗类型分类体系

## 1. 分类对象与结构

本分类体系用于描述一宗电信网络诈骗案件采用的策略和作案方式。它包含6个一级类别（L1）和18个二级类别（L2）：一级类别概括总体策略，二级类别区分具体实施方式。

分类以完整案件为单位，综合引流、诱导、转账和醒悟阶段的信息。同一案件可以同时包含多个二级标签。标签覆盖案件中实际出现的策略，包括接触受害人的诱饵、建立信任的身份，以及最终造成资金损失的方式。

判定遵循以下原则：

- 依据案件叙述中的具体行为和证据，不只根据案件标题、警方概括或受害人的称呼分类。
- 同一案件的不同策略可以组合出现；每个标签都应有对应证据。
- 区分用于建立信任的身份、用于吸引参与的机会，以及实际的交易或资金转移机制。
- 一级和二级标签配套使用；一个一级类别下存在多个二级类型时，分别记录各个组合。

## 2. 一级类别

| 一级类别 | 标签代码 | 核心含义 | 二级类型数 |
|---|---|---|---:|
| 身份冒充类 | `L1_Identity` | 冒充公权力、熟人、商业伙伴或具有可信身份的人员，利用相应信任实施诈骗。 | 4 |
| 金融信贷类 | `L1_Finance` | 围绕贷款、征信、投资及资金清退等金融需求和资金处置活动实施诈骗。 | 4 |
| 诱饵与机会类 | `L1_Bait` | 捏造就业、返利、赌博获利或中奖等机会，吸引受害人参与并付款。 | 3 |
| 交易类 | `L1_Transactions` | 围绕虚假的商品、服务或采购订单，在交易及履约过程中骗取资金。 | 3 |
| 长线社交与色情引流类 | `L1_Social` | 通过长期情感联系，或色情及性服务诱饵，吸引受害人参与并转移资金。 | 2 |
| 网络非法活动与敲诈勒索类 | `L1_Illegal` | 通过技术性账户接管盗转资金，或通过胁迫和勒索强制索取财物。 | 2 |

## 3. 二级类别详细定义

### 3.1 身份冒充类

| 二级类别 | 标签代码 | 定义与识别依据 |
|---|---|---|
| 公检法及政府机关冒充 | `L2_Id_Gov` | 冒充公安、检察院、法院及具有公权力的监管、清算等机构，或伪造其人员身份、文件、官网、APP、公众号和官方短信等载体。核心在于借用公权力及官方身份的可信度。 |
| 领导、熟人、公众人物及商业伙伴冒充 | `L2_Id_Acquaintance` | 冒充亲友、同事、领导、公众人物，以及已有或潜在的供应商、客户、企事业单位对接人等，滥用受害人对相应身份或关系的信任。 |
| 平台或客服冒充 | `L2_Id_Service` | 冒充电商、物流、金融或互联网平台的官方客服及相关工作人员，以退款、账户处理、服务办理等理由诱导受害人操作或付款。 |
| 军警等特殊身份冒充 | `L2_Id_Military` | 冒充军队、警察、消防等具有特殊身份的人员，借用其身份信誉实施诈骗。假冒军警消防采购人员是提示词中列举的典型场景。 |

### 3.2 金融信贷类

| 二级类别 | 标签代码 | 定义与识别依据 |
|---|---|---|
| 虚假贷款与信用卡 | `L2_Fin_Loan` | 以办理贷款或信用卡、低门槛借款等为诱饵，围绕获取贷款或信用额度的过程骗取资金。 |
| 虚假征信修复 | `L2_Fin_CreditFix` | 以征信异常、影响信用记录、注销贷款账户或校园贷等为由，诱导受害人进行所谓修复、注销或资金操作。 |
| 虚假投资理财 | `L2_Fin_Invest` | 以投资、理财、股票等机会和高额回报为诱饵，引导受害人进入虚假投资渠道或平台，造成资金损失，常表现为投入后无法提现或所谓亏损。 |
| 虚假资金清退与退款 | `L2_Fin_Recovery` | 针对已经真实遭受资金损失或存在待退资金的人群，以资金清退、退费、回款或追损为名实施二次诈骗。包括既往诈骗、投资亏损、P2P暴雷、培训机构或健身房关闭等背景下的虚假退款。 |

### 3.3 诱饵与机会类

| 二级类别 | 标签代码 | 定义与识别依据 |
|---|---|---|
| 刷单与任务返利 | `L2_Bait_Task` | 以点赞、模拟购物、刷单或完成任务获取佣金为名吸引参与，常先给予小额真实返利，再以连单、卡单、操作错误、账户冻结或解冻等理由要求继续付款。 |
| 虚假招聘与兼职 | `L2_Bait_Job` | 通过虚假的高薪兼职、手工活、日结或其他就业信息接触受害人，或利用招聘和就业承诺作为骗取资金的手段。 |
| 网络赌博与虚假福利中奖 | `L2_Bait_GambleAndLottery` | 以博彩漏洞、平台内部消息或稳赚不赔等说法诱导参与网络赌博；或以虚假福利、中奖为名，要求先缴纳税费、保证金等资金。 |

### 3.4 交易类

| 二级类别 | 标签代码 | 定义与识别依据 |
|---|---|---|
| 网络游戏虚假交易 | `L2_Tran_Game` | 围绕游戏账号、装备、皮肤等虚拟商品的买卖实施诈骗，包括将交易引向外部虚假平台。受害人可以是买家或卖家。 |
| 虚假购物与服务 | `L2_Tran_Shop` | 围绕二手商品、票务、代购或生活服务等交易实施诈骗，适用于个人之间的交易场景。诈骗者可以冒充买家或卖家，受害人也可以是个人买家或个人卖家。 |
| B2B欺诈与虚假采购 | `L2_Tran_Procurement` | 面向经营实体或商户，捏造大客户、企业或机构的大额采购需求，诱使作为卖方的受害人垫付货款、定金或向指定供应商付款。仅适用于B2B商业场景。 |

### 3.5 长线社交与色情引流类

| 二级类别 | 标签代码 | 定义与识别依据 |
|---|---|---|
| 网络婚恋交友 | `L2_Soc_Romance` | 通过较长时间的网恋、交友和陪伴建立情感信任，再引导受害人投资、转账、代操作账户，或参与其他骗局，包括通常被称为“杀猪盘”的情境。 |
| 重金求子及色情引流 | `L2_Soc_Sex` | 以色情内容、性服务或重金求子等为诱饵，吸引受害人进入骗局并逐步索取资金。其核心是即时或短期的生理欲望诱饵。 |

### 3.6 网络非法活动与敲诈勒索类

| 二级类别 | 标签代码 | 定义与识别依据 |
|---|---|---|
| 胁迫与敲诈勒索 | `L2_Ill_Extortion` | 利用隐私或性材料曝光、名誉受损、职场危机、数据灭失等威胁，强制要求受害人交付财物。核心是威胁所产生的被迫付款。 |
| 账号劫持与技术盗刷 | `L2_Ill_ATO` | 通过账户接管、木马、短信截获、屏幕共享窃密、远程控制或异地登录等方式，取得资金转移所需的控制权，并在受害人非主动授权的情况下盗转资金。 |

## 4. 重要判定边界

### 4.1 身份冒充与普通虚构身份

身份冒充标签关注利用相应身份获得的社会信任。对于熟人、公众人物、官方客服或长期商业伙伴，需要识别受害人信任该身份的具体情节。

在虚假采购中，诈骗者临时自称“大客户”，只是为捏造订单提供一个角色，不因此自动增加身份冒充标签。如果存在证照、名片、合同等持续建立可信身份的行为，或双方确有既往业务关系，则根据证据叠加相应身份标签。

### 4.2 公检法与政府机关载体伪造、口头背书

涉及军警时，应识别其身份在案件中的作用。冒充执法机关办案、调查或伪造执法材料，关注公检法及政府机关类；冒充消防采购员等特殊职业人员，关注军警等特殊身份类，并结合实际的交易或采购手段判断。不能只因出现“警察”一词，就自动叠加两个身份标签。

当前分类提示词明确区分以下情况：

- 伪造有关机关的文件、官网、APP、公众号、官方短信等载体，属于政府机关冒充的判定依据。
- 仅口头声称“银监会会冻结账户”或“向监管机关账户转账”，但未伪造有关载体，不仅凭这句话赋予 `L2_Id_Gov`。

这一边界用于约束标签判定，不能把所有提及政府或监管机构的案件都归入该类。

### 4.3 普通交易、B2B采购与游戏交易

- 个人购买商品或服务、出售闲置物品时被骗，使用 `L2_Tran_Shop`。
- 商户因虚假商业订单垫资，使用 `L2_Tran_Procurement`。
- 涉及网络游戏虚拟商品的交易，优先使用 `L2_Tran_Game`，不因受害人是买家还是卖家而改变。

### 4.4 刷单返利、虚假招聘与金融类策略

刷单平台内的连单、卡单、解冻或操作错误等追加付款要求，是 `L2_Bait_Task` 的组成部分。不能仅凭出现“解冻金”或“账户冻结”就增加金融类标签。

当案件同时有明确的虚假招聘或兼职信息，并通过刷单任务骗取资金时，可以记录招聘与任务返利两个标签，各自对应不同证据。

只有当受害人被引向一个独立的虚假投资渠道或平台，并实际涉及投资理财诈骗时，才考虑在任务返利之外增加 `L2_Fin_Invest`。

### 4.5 资金清退与普通客服退款

`L2_Fin_Recovery` 需要真实的既往资金损失、待清退资金或退费背景。物流、商品质量等普通消费问题中，假客服捏造理赔或退款并骗取转账，不因此归入资金清退类；应依据实际情节判断客服冒充等标签。

### 4.6 网络婚恋与色情引流

`L2_Soc_Romance` 依赖长期陪伴、关系经营和情感信任；`L2_Soc_Sex` 依赖即时或短期的性吸引。

当前提示词将“同城交友”等包装下、极短周期内安排线下见面的诈骗情节作为色情引流的判断线索。不能只因叙述使用“交友”一词，就将其归为长期婚恋诈骗。

### 4.7 色情引流与敲诈勒索

色情或性服务是最初的诱饵，后续若出现威胁曝光通讯录、私密影像等强制索款行为，可以同时记录 `L2_Soc_Sex` 和 `L2_Ill_Extortion`。两个标签分别描述引流方式和后续的强制收款机制。

### 4.8 技术盗刷与社交工程诱导付款

判定 `L2_Ill_ATO` 时，需要确认诈骗者取得控制权并独立实施资金转移。

- 受害人自行扫描付款码、确认金额或账户并完成转账，属于其主动操作的付款。
- 当前提示词也将受害人主动交出用于单次转账的验证码，归为社交工程诱导的授权付款。
- 诈骗者利用骗得的账户密码、登录或重置验证码接管账户，或者通过远控、共享屏幕窃密、木马等手段自行划款，属于技术盗刷的判定情境。
- 一个辅助判断是：受害人不再提供新的验证码，诈骗者是否仍能依靠已取得的控制权继续盗转资金。

诈骗类型中的 `L2_Ill_ATO` 与心理分类中的 `Non_Cognitive` 分别描述作案类型和单笔资金转移的机制，两者不能互相替代。

## 5. 标签表示

每个输出元素拼接一个一级代码和一个二级代码。例如，同一案件同时包含长期婚恋与虚假投资时，可表示为：

```json
{
  "reason": "案件同时包含长期情感经营和虚假投资诱导。",
  "labels": [
    "<L1_Social><L2_Soc_Romance>",
    "<L1_Finance><L2_Fin_Invest>"
  ]
}
```

任务提示词要求同时提供 `reason` 与 `labels`，其中分析字段位于标签字段之前。

微调版使用对应的特殊token形式，如 `<|L1_Social|><|L2_Soc_Romance|>`；baseline版使用普通文本形式，如 `<L1_Social><L2_Soc_Romance>`。分类含义与层级关系相同。
