# Goal
深度分析上述案件描述，锁定醒悟阶段的内容，并逆向追溯转账和诱导阶段的末尾动态，提取导致诈骗终止的最核心触发点组合，严格映射到预设的8大扁平化标签体系中。

# Processing Logic
1. **逆向锚点扫描 (Reverse Anchoring)**：
   - 定位醒悟阶段中的报案原因或醒悟触发点。
   - 强制向前追溯转账阶段的最后几句话，寻找触发觉醒的前置“客观事件”。
   - **绝对过滤器**：忽略一切毫无来由的主观直觉（如“越想越气”、“心里发毛”）。必须抓取背后的实质支撑点：物理状态（没钱了）、第三方动作（警察上门、骗子拉黑）、信息验证（去银行问）、预期落空（等不到钱）、规则漂移（提现失误需再补单）。
2. **底层机制映射**：严格根据以下【标签字典】，为终止事件匹配最精准的分类。如果存在多重原因（如：没钱了 + 朋友劝阻），可输出标签组合。

# 标签字典
1. <System_Intervention> - 外部系统干预：公权力或金融机构系统主动强制阻断，如反诈预警、96110来电、银行卡被风控锁定、警方上门。
2. <Social_Intervention> - 强关联人干预：熟人（家人/朋友/同事等）介入劝阻，或受害人主动询问熟人后被点醒。（注：若找“被冒充的真人”核实，归为外部验证）
3. <External_Validation> - 外部权威求证：受害人起疑后向权威渠道（银行柜台、派出所、官方客服）或冒充案中向被冒充者本人核实，被明确告知诈骗。
4. <Fraud_Awareness_Trigger> - 反诈认知触发：因接触反诈内容而醒悟（上网搜索发现相似骗局案例、看到反诈节目、看到平台反诈提醒、同案例受害者的揭露、回想起之前接受过的反诈教育等）。
5. <Internal_Logical> - 逻辑信任崩塌：骗子未断联且仍在编造理由索款，受害人凭自身常识识破荒谬性（如规则漂移、无尽补单），主动拒绝并醒悟。禁用场景：仅被动发现资金被划走。
6. <Commitment_Failure> - 预期承诺落空：骗子曾给出具体兑现承诺，受害人尝试兑现时发现无法实现（无法提现、迟迟不到账、货不对板等），且该落空直接触发醒悟。
7. <Attacker_Disengagement> - 攻击方断联/撤离：骗子主动终止联系（拉黑、群解散、APP无法登录、店铺注销等）。
8. <Objective_Termination> - 客观条件阻断/被动终止：因客观能力丧失或被动损失而终止，如资金枯竭、发现非授权扣款、物理信道中断。

# 易错判别要点
- 主动识破 vs 被动发现：骗子仍在行骗，受害人识破拒绝 → <Internal_Logical>；只是发现钱被划走 → <Objective_Termination>。
- 熟人 vs 机构：联系熟人 → <Social_Intervention>；走进银行/派出所/找被冒充本人核实 → <External_Validation>。
- 系统主动干预 vs 受害人求证：系统/机构主动拦截 → <System_Intervention>；受害人主动求证 → <External_Validation>。
- 若案情末尾仅以一句话提到"曾接受过反诈宣传"，受害人的实际觉醒另有他因，则**不打**<Fraud_Awareness_Trigger>。
- 必须抓取醒悟前的客观事件，忽略纯主观直觉（如“越想越气”）。

## Example 1
Input:
【引流】
2022年9月29日10时30分，受害人被不明身份者拉入一个微信群，对方称要想长期做任务挣佣金可以下载一个"汪多宝"APP。
【诱导】
受害人下载了"汪多宝"APP并注册账号。后来客服专员称想赚更多的钱可以通过网址链接进入"三超百货"页面。
【转账】
受害人为了赚更多钱，投入较少的钱很快有了收益且可以提现。随后，其向对方指定账户转账42480元人民币。之后受害人看到有收益便尝试提现，但系统显示提现时操作失误，需要再抢一单。
【醒悟】
受害人意识到被骗，遂于2022年9月30日15时05分报警。

Output:
{
    "analysis": "锚定 awake 阶段，受害人仅描述为'意识到被骗报警'。逆向追溯 transfer 阶段末尾发现，受害人转账大额资金并尝试提现时，遭遇了'系统显示提现操作失误，需要再抢一单'的连环套路。骗子仍在继续编造理由要钱，受害人由于识破了这种'规则漂移'和'无底洞'的荒谬性，主观常识觉醒，从而停止支付。",
    "labels": ["<Internal_Logical>"]
}

【诱导】

【醒悟】
受害人没办法弄到钱，内心觉得慌张，于是拿着手机去家附近的派出所问民警，被告知是诈骗。

    "labels": ["<Objective_Termination>", "<External_Validation>"]
}

## Example 3
Input:
【引流】
2022年8月3日，受害人在某投资交流群内，被群内"导师"推荐了一款名为"聚财宝"的投资APP，声称内部数据可预测涨跌，稳定月收益20%。
【诱导】
受害人下载APP后，在导师指导下小额试投500元，三天后账户显示盈利320元且可以提现，建立信任。导师随后推荐"VIP大单"，称本金越大收益越高。
【转账】
受害人先后向对方提供的多个银行账户转账共计78000元。最后一笔转账完成后，受害人在APP内申请提现，提现申请一直显示"审核中"。受害人随即尝试联系导师，发现对方微信已将其拉黑；再打开APP，显示"服务器维护中"，此后始终无法登录。
【醒悟】
受害人发现联系不上对方，平台也无法登录，意识到被骗，当日前往派出所报案。

Output:
{
    "analysis": "锚定醒悟阶段，受害人因'导师微信将其拉黑'且'APP无法登录'而意识到被骗。逆向追溯转账阶段末尾，骗子在完成收割后主动切断全部联系渠道——同时拉黑微信并关闭平台，属于典型的攻击方主动撤离。提现'审核中'是攻击方撤离后的自然状态，而非独立的'等待落空'触发点，无需附加 Commitment_Failure。",
    "labels": ["<Attacker_Disengagement>"]
}
